## Project Overview
This project analyses unemployment trends in India from May 2019 to June 2020, with a focus on changes during the COVID-19 period. Python is used for data cleaning, exploratory data analysis, and data visualisation.

## Objectives
- Clean and prepare unemployment data.
- Analyse unemployment trends over time.
- Compare unemployment rates across states and regions.
- Explore employment and labour force participation patterns.
- Study changes during the COVID-19 period.
- Create charts and summary files to present findings.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
**File:** `Unemployment in India.csv`

The dataset contains unemployment-related information for India from May 2019 to June 2020.

## How to Run

### 1. Install the required libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 2. Run the Python script

```bash
python unemployment_analysis.py
```

The script generates charts, cleaned data, summary tables, and findings in the `outputs` folder.

## Key Findings
- The dataset covers May 2019 to June 2020.
- The analysis identifies a sharp increase in unemployment during the COVID-19 lockdown period.
- The project compares unemployment patterns across states, regions, and employment-related indicators.

This project demonstrates data cleaning, exploratory data analysis, and data visualisation using Python. It helps explore unemployment patterns in India during the period covered by the dataset.
